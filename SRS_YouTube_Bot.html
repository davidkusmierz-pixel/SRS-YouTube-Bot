📨 Wysyłanie na Discorda

Ten przycisk służy tylko do miniaturki. Jeśli powiadomienie LIVE zostało już wysłane przez ten panel, zaktualizuje miniaturkę w tej samej wiadomości — nie wyśle nowego powiadomienia.

Gotowe. Wpisz klucz API i webhook, a następnie wybierz przycisk.

ℹ️ Jak używać

1. Wklej klucz YouTube Data API v3 i webhook kanału Discord.
2. Zostaw uchwyt @srs-dawid-y6q albo wpisz uchwyt swojego kanału.
3. Kliknij odpowiedni przycisk. Bot znajdzie materiał i wyśle tytuł oraz link na Discorda.
4. Przy powiadomieniu LIVE bot oznaczy rolę Społeczność.

Wysyłasz powiadomienia ręcznie przyciskiem. Panel zapamiętuje identyfikatory wysłanych materiałów, więc zmiana miniaturki i ponowne kliknięcie przycisku nie wyśle drugi raz powiadomienia o tej samej transmisji. Zapisane LIVE nie będą też ponownie wysyłane jako zwykły film. Zapis działa w tej samej przeglądarce na tym urządzeniu.
